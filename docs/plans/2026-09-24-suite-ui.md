**Goal:** Cloud Codex's colours, focus, buttons, dialogs and shell resolve from the shared token
package, gated so they cannot drift back, and in suite mode Codex carries the suite's identity
cluster, keeps deep links through sign-in, and links a document to the tasks that reference it.

class-selecting tests never change. Suite mode is one environment variable.

**Tech stack:** React 19, Vite 7, plain CSS custom properties in OKLCH, Vitest 4 + jsdom, the
package's `node:test`-clean ESM gates, `iris` for looking.

## Global constraints

The identity plan's global constraints apply. In addition:

- **Values only, class names kept.** Tests select by class (SearchBox 17 places, ReadOnlyContent 12,
  and others); a renamed class is a broken test that was right.
- **No `position`, `overflow` or `transform` change on or around `.editor-container` or `.tiptap`.**
  Every comment highlight and remote cursor is positioned against them, with no test coverage.
- **The vendored directory is never edited here.** A change to a primitive is a package PR upstream,
  then a re-vendor PR here, and the checksum test's failure message says exactly that.
- **Suite mode off means the markup is unchanged**, pinned by a render test in every PR that touches
  the shell or the front door.
- **After-captures** of every touched route go beside the before-captures, and the PR body explains
  every visible difference.

### Task 1.3 Token discipline against a ledger

`tests/design/buckets.js` does the grouping, so the test and a report command share it. The three
scanner names are the ones Cloud Command's TypeScript gate exports today; re-read the vendored
`gates/token-discipline.mjs` exports before writing the import.

```javascript
/**
 * Groups design findings into ledger buckets: per file, and per section banner inside index.css
 *
 * All Rights Reserved to Cloud City Computing, LLC 2026
 * https://cloudcitycomputing.com
 */

import { readFileSync, readdirSync, statSync } from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import {
  scanRawColorLiterals, scanAccentRampPositions, scanSuppressedOutlines,
} from '../../vendor/cloud-city-design/gates/token-discipline.mjs';

export const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '../..');
const SCANNED = /\.(css|js|jsx|html)$/;

// index.css uses two banner shapes: a title on the line under a `/* ====` rule,
// and the one-line `/* ─── GitHub Integration ─── */`.
export function banners(source) {
  const lines = source.split('\n');
  const found = [];
  lines.forEach((line, i) => {
    if (/^\/\* ={5,}/.test(line) && lines[i + 1]) found.push({ line: i + 1, name: lines[i + 1].trim() });
    const inline = /^\/\* ─── (.+?) ─+ \*\/$/.exec(line);
    if (inline) found.push({ line: i + 1, name: inline[1] });
  });
  return found;
}

function walk(dir) {
  return readdirSync(dir, { recursive: true, encoding: 'utf8' })
    .map((entry) => path.join(dir, entry))
    .filter((file) => SCANNED.test(file) && statSync(file).isFile());
}

export function liveBuckets() {
  const buckets = {};
  for (const file of [path.join(ROOT, 'index.html'), ...walk(path.join(ROOT, 'src'))]) {
    const source = readFileSync(file, 'utf8');
    const rel = path.relative(ROOT, file);
    const findings = [
      ...scanRawColorLiterals(source, rel),
      ...scanAccentRampPositions(source, rel),
      ...scanSuppressedOutlines(source, rel),
    ];
    const marks = rel === path.join('src', 'index.css') ? banners(source) : [];
    for (const finding of findings) {
      const mark = marks.filter((b) => b.line <= finding.line).pop();
      const key = mark ? mark.name : '(file)';
      buckets[rel] ??= {};
      buckets[rel][key] = (buckets[rel][key] ?? 0) + 1;
    }
  }
  return buckets;
}
```

`src/lib/focus-trap.js`:

```javascript
// What counts as a Tab stop. `button:not([disabled])` is why an in-flight
// control should use aria-disabled: a real `disabled` on the focused button
// drops focus to <body> and the trap stops seeing Tab.
export const FOCUSABLE =
  'a[href], button:not([disabled]), input:not([disabled]), textarea:not([disabled]), ' +
  'select:not([disabled]), [tabindex]:not([tabindex="-1"])';

// Keeps Tab inside `root`. Only the boundary presses are intercepted, and the
// DOM is re-queried on every press, because a modal's controls change under it.
export function trapTab(event, root) {
  if (event.key !== 'Tab' || !root) return;
  const stops = [...root.querySelectorAll(FOCUSABLE)].filter((el) => el.closest('[inert]') === null);
  const first = stops[0];
  const last = stops[stops.length - 1];
  if (!first || !last) return;
  const current = document.activeElement;
  if (event.shiftKey ? current === first : current === last) {
    event.preventDefault();
    (event.shiftKey ? last : first).focus();
  }
}
```

`src/lib/overlay.js`:

```javascript
// A counter, not a boolean: a modal opened from inside another must not
// un-inert the page when the inner one closes.
let open = 0;

export function declareOverlay(appRoot = document.getElementById('root')) {
  open += 1;
  appRoot?.setAttribute('inert', '');
  let released = false;
  return function release() {
    if (released) return;               // idempotent: two closes release once
    released = true;
    open -= 1;
    if (open === 0) appRoot?.removeAttribute('inert');
  };
}

export const openOverlayCount = () => open;
```

`src/lib/focus-claim.js`:

```javascript
// The element focus returns to when the modal stack empties. showModal
// replaces its content in place (clearInner, then render), so the opener of
// the FIRST modal is the one to restore; a modal opened from inside a modal
// must not overwrite it with a button that is about to be unmounted.
let opener = null;

export function rememberOpener(element = document.activeElement) {
  if (opener === null && element instanceof HTMLElement) opener = element;
}

export function restoreOpener() {
  const target = opener;
  opener = null;
  if (target && target.isConnected) target.focus();
}
```

// Reads process.env by literal name, never through a parameter, so W6-CDX-32's

export function readSuiteConfig() {
